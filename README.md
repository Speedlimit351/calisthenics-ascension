# ASCEND

A free, local-first 100-level calisthenics progression tracker.

Start at Level 1, build through ten ranks, and progress across push, pull, legs, core/compression, balance/inversion, straight-arm/rings, mobility/control, and grip/explosiveness.

Each level requires 3–7 qualifying training days. One day can count only once per calendar date. The rank-up trial runs eight consecutive standards with timed rest and a total time cap. Exercise completions are self-recorded.

Progress, personal bests, completed tests, achievements, and history are stored in this browser. Use Progress tools to export or restore a JSON backup.

This is a static site with no build step or paid service. See the repository files for publishing and progression notes.
